# 🩺 Health Prediction App (AI Powered)

A Python-based AI web application that predicts **health remarks** based on patient data like glucose, haemoglobin, and cholesterol using Google Gemini AI.

---

## 🚀 Features
- AI-powered health remark generation
- Simple web interface using Streamlit
- Real-time prediction
- Easy to use and lightweight

---

## 🛠 Tech Stack
- Python 🐍
- Streamlit
- Google Generative AI (Gemini API)
- Git & GitHub

---

## 📊 How It Works
1. User enters health parameters:
   - Glucose
   - Haemoglobin
   - Cholesterol
2. Data is sent to Gemini AI model
3. AI generates a short medical remark
4. Result is displayed instantly
